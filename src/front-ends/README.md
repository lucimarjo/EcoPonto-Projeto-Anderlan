# 🖥️ Front-Ends

O Front-end do EcoPonto é estruturado em dois front-ends, cada um responsável por um público.
Cada front-end será dividido em micro Front-ends. Cada serviço possui responsabilidades e tecnologias exclusivas:

- 📱 **Kotlin**: Responsável pela interface e interação do usuário no Aplicativo utilizando Jetpack Compose como Framework.
  Consulte o [README do serviço Kotlin](./mobile-Kotlin/README.md) para detalhes de arquitetura e tomadas de decisão.
- 🌐 **Javascript**: Responsável pela interface e interação do usuário no Site do projeto. Utiliza Vue.js como Framework.
  Consulte o [README do serviço Javascript](./web-JS/README.md) para detalhes de arquitetura e tomadas de decisão.
