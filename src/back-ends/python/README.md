# 📍 Python

Responsável por:

- Microsserviço de geoprocessamento;
- Integração direta com as APIs do _OpenStreetMap_.

## 🤔 Por que escolhemos

O **Python** foi escolhido para ser quem vai conversar com a API do _OpenStreetMap_ pois possui um ecossistema de bibliotecas geográficas mais simples e eficiente do mercado e permite integrar funcionalidades de análise de dados ou até inteligência artificial caso queiramos adicionar no futuro.
Já o **FastAPI** foi preferido por gerar a documentação interativa da API de forma instantanea, como também, ser considerado o Framework mais rápido do mercado.
